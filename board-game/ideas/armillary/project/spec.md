# Armillary — draft spec

Stacking-disc verification game. Source of truth: `board-game/ideas/armillary/brief.json`.

- `plinth_axle` — 190mm dia x 22mm drum, topped by a 40mm-tall, 12.2mm-dia
  axle post. 8 sockets (14mm dia x 10mm deep) on a 75mm-radius ring, 8
  index grooves on the rim at the same angles, small raised "constellation"
  dots between the sockets.
- `tier_disc_a/b/c` — 190mm dia x 10mm discs, 13mm center bore (free-spin on
  the post), 3 x 9mm windows each at a distinct subset of the shared 8
  position ring, one grip tab each (rounded paddle / triangular fin /
  double-prong), one 1mm witness notch on the rim.
- `marker_peg_tri/square/penta/hex` — 4 each, 11mm-across polygonal prism,
  20mm tall, domed top. Drop into any empty plinth socket.
- `probe_pin` — 1, 6mm x 40mm shaft under a 16mm x 6mm flared head. Shaft
  length calibrated to be flush exactly when a socket is a clear shaft
  through the plinth + all 3 discs.

See `brief.md` for the full prose and `brief.json` for every asserted
number.
