# CAD QUESTIONS — what the pipeline asks when a prompt leaves a gap

Every clarifying question the CAD pipeline has parked a job on, verbatim,
with the answer given and the spec field it came from.

Each question is a precise statement of something the `cad_prompt` should
have carried and did not. `board-game-cad-writer`'s standing job is to fold
the recurring **categories** here into its prompt template, and its target
metric is questions-asked trending to zero — every question also costs the
idea Build Reliability points.

Written by `/goal`'s learn phase from each build's `session.json` `answer`
events. Group by category, not by idea: categories are what a template can
pre-answer.

An answer marked `UNSTATED:` means the spec genuinely did not settle the
question and the pilot took the most conservative reading. Those are the
highest-value rows in this file — they are gaps in the *vision*, not just
the translation, and they belong in the ideator's lessons too.
