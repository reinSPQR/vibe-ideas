## Per-idea notes

1. **Thistlewood Market** — Differentiation verified via two searches ("fixed pre-cut recesses player tray drafting scarcity", "'stall tray' fixed shaped recesses"); results returned only generic tile-placement guides, a patent about corner-locating projections (not shape-locked recess categories), and standard Azul/Mille Fiori references — no shipped game combining a fixed non-negotiable per-shape-category tray with open-market tile drafting was found. Claim holds up. Not built this turn — Differentiation only.
2. **Cipher Row** — Differentiation verified via two searches on the claim's own wording ("codemaker voluntarily reveals peg for bonus points lock cap breaker bribe token", "partial reveal trade information for points snap cap peg"); both returned only standard Mastermind/Code Breaker products and an unrelated party deduction game, no partial-reveal-for-bonus + bribe-token economy. Claim holds up. Built this turn but the CAD job parked on `awaiting_questions` before any manifest or build directory was created — no printability or fidelity data exists, and no purchase-intent data was generated, so Producibility and Buyability are both hard-gated to 0.
3. **Threshing Floor** — Differentiation verified via two searches ("resources physically stacked on personal post visible tower scoring", "grain discs slide onto player peg tower instead of tracked on paper"); neither surfaced a worker-placement game using a rigid personal stacking post as the core visible-progress mechanic (results were generic worker-placement guides and unrelated farming titles). Claim holds up. Built this turn but also parked on `awaiting_questions` — no manifest/build directory exists, so Producibility and Buyability are both hard-gated to 0, identically to Cipher Row.
4. **Market Wheel** — Differentiation partially weakened: a search for "board game bet on slot number wheel rotates unknown amount before reveal" surfaced Carcassonne: Das Schicksalsrad's "Wheel of Fate," which does combine tile-laying with a random 1-3-space wheel rotation — but its wheel drives bonus meeple movement/scoring, not a claimed-number-before-spin drafting reveal, so it's a loose thematic neighbor rather than a mechanism match. The core "claim a position, then see what the spin left there" hook survives, but the near-miss and single supporting search (vs. two clean passes for other ideas) caps this below the top tier. Not built this turn — Differentiation only.
5. **Foghorn** — Differentiation: the idea's own text names only Sea Change as a comparable (an automatic rules-triggered trump change, correctly distinguished from this idea's player-chosen public dial spin). Per the orchestrator's flag, I independently searched "Fox in the Forest" and "Trumps" by name. Fox in the Forest sets trump once via a Decree card at the start of a round, changeable only if a player plays the odd-numbered Fox card to swap it — not an every-trick, trick-winner-controlled mechanism, so it does not match. The card game "Trumps" (pagat.com) gives each player a personal hidden trump card they can reveal at will — a different structure (individual per-player trump, not a shared dial the trick winner sets for everyone). Neither invalidates the claim, but the idea's own search should have checked these two obvious classics by name given how central "dynamic trump" is to its pitch, rather than only checking Sea Change — docked for that gap even though the claim survives. **Built this turn, `status: done`.** Printability from `manifest.json`'s `review_fix.printability` (8.97/10 → 17.9/20 scaled). Concept fidelity (5/20): parts did physically separate into distinct pieces this turn (a genuine improvement over the last two turns' single-fused-blob failures) — 4 sawtooth racks and a separate box + lid are all present and roughly right-shaped. But the build lost nearly everything the `cad_prompt` specified as color-coded: the trump dial and its base plaque are fused into one static, non-rotating piece (destroying the core "spin the dial" mechanic entirely, not just its finish), the 48 individually numbered/colored suit tiles are fused into a single continuous ~40-cell mat rather than 48 loose, holdable, playable chips (destroying the ability to hold and play individual tiles — fundamental to a trick-taking game), the grey trick collection tray specified in `components`/`cad_prompt` is entirely absent from the build, and every part that was supposed to carry one of 4+ distinct colors (dial quadrants, suit tiles, player racks) printed in one uniform monochrome terracotta instead. Because the two lost features (rotating dial, individually-holdable tiles) are the literal core of the game's twist and its basic playability, not decorative details, fidelity is scored low despite the real structural improvement in part separation.
6. **Seam Works** — Differentiation fails a serious check: a search for "shared board tile connection race any player completes another player's link to claim resource" led to Indigo (Reiner Knizia, 2003), and a direct fetch of Indigo's rules confirms it already implements almost exactly the claimed novel hook — "a tile placed by one player can benefit another... a strategic placement by one player could complete a route that delivers a gem to an opponent's edge, allowing that opponent to claim it." Seam Works' own differentiation text checked only Gold Mine and Fault!, missing this much closer structural match entirely (gem-routing-to-edge vs. ore-chain-to-entrance is a detail-level difference, not a structural one — both hinge on "any player's placement can trigger any other player's claim the instant a connection completes"). Scored low as a genuine, not narrow-search-phrasing, miss. Not built this turn — Differentiation only.
7. **Canal Locks** — Differentiation (reskin #1 of 2, within cap, scored on merits): confirmed base game is the public-domain Dots and Boxes; two searches ("'Canal Locks' OR 'dots and boxes' canal theme peg rod connector board game" and a follow-up specific to Canal Locks by name) found no existing canal/lock-themed Dots and Boxes product — the reskin is genuinely unclaimed styling, but per the rubric a reskin with no rule change caps below "new"/"twist" ideas regardless of execution quality. Not built this turn — Differentiation only.
8. **Loom Weave** — Differentiation (reskin #2 of 2, within cap, scored on merits): confirmed base game is the public-domain Nine Men's Morris; a search for "Nine Men's Morris weaving loom textile theme spool bobbin board game" returned only standard wood/travel editions of the base game itself, no textile-themed variant. Genuinely unclaimed styling, same reskin ceiling as Canal Locks applies. Not built this turn — Differentiation only.
9. **Lantern Keepers** — Differentiation verified via two searches ("cooperative board game shared rotating spotlight beacon protects only one lane at a time," "'lighthouse' cooperative board game beacon light one direction ships drift toward rocks other lanes"); both surfaced only Beacon Patrol (a relaxed cooperative tile-laying/exploration game with no single-lane-illumination triage mechanic) and The Last Lighthouse (already correctly identified and distinguished in the idea's own text as an unrelated solo card game). No shipped game with a single shared rotating beacon that can protect only one of several simultaneously-advancing lanes was found. Claim holds up cleanly. Not built this turn — Differentiation only.
