## Per-idea notes

1. **Tactile Suit-Rank Corner Clips** — Verified: commercial braille card products (thelowvisionstore, braillebookstore, ILA) are all full replacement decks, and MyMiniFactory's "Parametric Playing Cards with Optional Braille Dots" is a whole-card reprint, not a retrofit clip; OderWat's Printables "Card Clip" is confirmed stability-only with no tactile coding, exactly as the rationale described it. Differentiation survives search because the claim was scoped narrowly to the specific retrofit-clip mechanism. Demand is real but the addressable audience (blind/low-vision hobbyist card players) is small even if gift-able, capping it below a mass-hobbyist ceiling. The `prompt` gives concrete bump/notch geometry and a configurable slot-clearance parameter — near-ideal producibility spec.

2. **Custom Engraved Player Nameplate Meeples** — A direct search for "3D printed personalized meeple" turned up 1,000+ active Etsy listings, including already-finished (not DIY-file) 3D-printed PLA personalized meeples sold ready to ship — this directly contradicts the rationale's claim that current options are either hand-finished-only or unpersonalized static files. The "per-order parametric pipeline" angle is a real structural difference from a single static STL, but it's a thin distinction in an already-saturated commodity space, so this caps at the me-too ceiling. Demand itself is undeniable (huge existing market proves willingness to pay), and producibility/margin are both solid and well-specified.

3. **Flip-and-Write Field Clipboard** — Demand verified: BGG runs an active, ongoing 2026 Roll/Flip-and-Write Challenge geeklist, confirming a real sustained community, though search also surfaced that the genre's 2019-2020 "boom" has cooled, so this is a real but moderate (not surging) niche. Differentiation is weaker than claimed: generic marker-holder clipboards and hand-held dry-erase boards "with a clip that secures a marker" already exist as an established product category (patented, sold at DryErase.com); the flip-and-write framing plus integrated kickstand is a real but narrower angle than "no result combined" implied. At 120g/3.5hr print for $19, margin is thin relative to machine time for a single-color part.

4. **Modular Cycle Turn-Order Wheel** — The Rebirth Kennerspiel des Jahres 2026 win is confirmed true (ICv2, BGG, wericmartin.com), but the causal leap from "one game with a cyclical theme won an award" to "demand for a generic turn-order-wheel accessory" is a stretch, not a demonstrated purchase signal — scored down accordingly rather than capped outright since the underlying fact is real. Differentiation fails on direct search: Etsy's "Modular D&D Initiative Tracker" already offers snap-together segments that can be added or removed to match player count on a shared base, which is essentially the exact mechanism this idea claims is unclaimed. This is the lowest score of the turn.

5. **Gridfinity Sleeved-Card Vault** — Gridfinity adoption is well-verified (active GitHub catalog, hundreds of Printables/MakerWorld listings). However, search found "Gridfinity Sleeved Card Deck Holder / Tray" already exists as a purpose-built sleeved-card Gridfinity module, and a pin-retained (non-magnet) card holder already exists too — the base concept (sleeved cards + Gridfinity footprint) is already crowded; only the spring-loaded browsable-follower mechanism is a genuinely unclaimed angle, which caps differentiation below top marks. At 90g plus a spring insert and a 4-hour print for $24, margin is plausible but not generous given the machine time.

6. **Grip-Assist Piece Topper Retrofit Set** — Demand verified: Printables' "Easier to Handle Generic Game Tokens" by Tantalus is confirmed real and matches the rationale's description exactly, and ILA/Rehabmart/LS&S dexterity-aid categories are real retail niches. Differentiation holds up: search found only generic non-gaming accessibility grips (pen grips, bottle openers) and a token-replacement (not retrofit) product, not the specific non-destructive dice/standee/token retrofit combination claimed here. Solid, well-specified producibility across three simple shape families.

7. **Legacy Campaign Spoiler Vault** — The ceremonial-opening culture around Gloomhaven's sealed envelopes is confirmed via the Gloomhaven Wiki's own "Sealed Content" page. Search found existing Gloomhaven/Pandemic Legacy storage organizers but none with a lock mechanism, so the magnetic-key-disc lock angle appears genuinely unclaimed. This is a niche-within-a-niche (owners of specific legacy campaign games who want locked ceremonial storage), and at 140g/5hr print time for $27, the rationale's price-ceiling justification ("legacy buyers pay $80-100 for games") doesn't clearly justify this specific accessory's own economics — margin scored down accordingly.

8. **Player-Aid Rail Clip** — The rationale's demand claim is generic and uncited ("multiple modern euro games ship with... player-aid cards," "community-made... accessories appear repeatedly") with no specific named source, fan community, or sales category to check — per the standing rule on unverifiable trend claims, this caps demand well below what a cited, checkable fact would earn. Differentiation held up under search (found stacking multi-card holders, DIY clothespin adaptive holders, and a two-tier fan card holder, but nothing matching this specific single-card, external-edge-clamp use case). Best producibility/margin profile of the set: one part, one flex joint, tight tolerance called out, fast cheap print.

9. **Board Game Library Circulation Audit Tray** — Institutional circulating board-game programs are well-verified (Programming Librarian's own guide, multiple university/public library libguides on checkout policies and per-bag component counting). Differentiation holds up: search found only inventory-tracking software (GameLedger) and hobbyist game-specific organizers, not a generic relabelable institutional audit tray. But the addressable buyer is a small institutional market, and at 180g/6hr print time for $32/unit the machine-time-to-revenue ratio is the weakest in the set — a genuine epic without a strong enough price-ceiling case, since institutional bulk buyers typically expect volume discounts that erode this further.

10. **Con Badge Charm Clips** — The badge-ribbon trading culture is confirmed via CONvergence's own "Ribbons" program page. But differentiation fails directly: Etsy already sells a "3D Printed Meeple Lanyard Name Badge... Personalised" from a shop explicitly marketed for "gaming shows and conventions," plus existing D20 dice charms and meeple lanyard charms — directly contradicting the claim that existing badge attachments are fabric/paper only, not rigid 3D printed charms. Excellent margin and producibility (tiny parts, fast print, clear tolerances) couldn't offset the differentiation failure.
