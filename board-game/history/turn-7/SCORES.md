## Per-idea notes

1. **Cairn Climbers** — Verified via search that Junk Art's "Mad Art" mode already has players "working together on a single or combined plinth," directly contradicting the idea's own framing that a shared central stack (vs. Junk Art's supposedly "personal tower") is the novel element — the genuinely surviving differentiator is only the blind bag draw of unknown-weight stones (Junk Art always uses visible, player-chosen pieces), so differentiation is scored down accordingly. Demand and fun both cite solid, checkable comparables (Junk Art, Rhino Hero, Can't Stop, Incan Gold); producibility is clean single-piece stone geometries with an explicit flatness tolerance called out.

2. **Whistleblower** — Verified directly (not just searched) that Suspicion (Wonder Forge) uses cards, dice, and a paper deduction pad rather than any rotating reveal mechanism; two differently-worded searches turned up no shipped social-deduction game using a dual-layer rotating-ring simultaneous vote reveal. Fun_case names a specific comparable moment (Secret Hitler's simultaneous policy reveal) rather than asserting fun generically. Highest score of the batch and a model for how to verify a named competitor's actual mechanism, not just its existence.

3. **Orbital Blockade** — Honestly classified as a reskin (Nine Men's Morris ruleset genuinely unchanged, correctly not oversold as a "twist"); search across the many wood/leather/nautical Nine Men's Morris variants on Etsy found no space/satellite-themed version. Fun is entirely, and correctly self-acknowledged as, inherited from the base game, which caps that score; producibility is minimal (2 part types, no assembly, loose peg fit) — best in class this turn alongside Meteor Field.

4. **Riverworks** — Search found no shipped pick-up-and-deliver game using a physical sliding-peg lock-water-level gate as a pass/fail gate (Canal Mania and generic p&d titles don't use this component); the mechanism is genuinely distinct. Producibility is the one weak spot: the same slider-with-detents joint repeats across 5 independent Lock Gate components, and while the notes justify the joint type as a known, validated FDM family, the repeated-count risk isn't fully mitigated, capping this score below the batch's other clean-joint entries.

5. **Ember Court** — Differentiation survives search; the closest analog found (FYFE's double-sided scoring-board flip) isn't trick-taking, so the specific combination holds. Demand is capped: the claim that Skull King and The Crew "each sold hundreds of thousands of copies" could not be confirmed — BGG's ratings pages didn't surface the actual figures in search results, making this an unverifiable specific number under the rubric's cap. Fun_case names Hearts and The Crew directly; producibility is clean (45 flat double-sided tiles, zero joints).

6. **Foundry Row** — Differentiation is genuinely narrow versus both Tzolk'in (workers physically ride the gears) and the Rondel family (a marker moves around a fixed action ring) — this design's static-slot/rotating-lookup-window structure is structurally distinct from both and survived search. Demand is capped: the "Tzolk'in... 25,000+ ratings" figure could not be pinned down via search (inconclusive, not contradicted), so the unverified-specific-number cap applies. Reuses the same validated pivot-disc joint family as ideas 2 and 7.
